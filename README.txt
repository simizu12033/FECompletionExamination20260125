2026.1.25 FE修了試験 過去問演習システム

全60問／合格基準36問／試験時間90分
元教材FECompletionExamination20221211_v7の画面構成とCSSを継承。
問題画像は提供されたQ1.png〜Q60.png、正答は提供された解答PDFと照合。
解説・60枚の図解・用語カード・8問の条件変更演習・60問の説明欄を収録。

使い方
index.htmlをブラウザで開くと利用できます。インターネット接続やビルドは不要です。
全問に回答→採点→学習レポート→再回答と復習、の順で進みます。
解答、初回成績、理解チェック、説明欄、カードの復習予定をブラウザに自動保存します。
同じ端末・ブラウザ・URLで利用してください。サイトデータ削除で記録が消えます。

GitHub Pagesへの配置
新しいリポジトリ（例：simizu12033-FECompletionExamination20260125）を作り、
このフォルダの中身をリポジトリの直下へアップロードします。
Settings > Pages > Deploy from a branch > main / (root) > Save。
assetsフォルダも省略せず配置してください。旧試験のリポジトリとは別にすると旧版を残せます。

この納品物はGitHubへのアップロード用です。GitHub上の既存サイトは変更していません。
問題の著作権は原著作権者に帰属し、解説等は学習用の独自教材です。
